# Hospital Management System

**SRN:** PES1UG24CS611, PES1UG24CS619, PES1UG25CS839

A Patient Record and Appointment Management System for hospitals to manage patients, doctors, departments, appointments, admissions, billing, notifications, and reports.

## 📁 Documents

All project documentation is available inside the `Documents` folder:

| File | Description |
|---|---|
| `SRS_Document.docx` | Software Requirements Specification — lists all Functional and Non-Functional Requirements of the system in table format. |
| `Test_Plan_Document.docx` | Test Plan — contains Unit, Integration, and System test cases for every module (Login, Patient Records, Doctors, Appointments, Admission/Discharge, Billing, Notifications, Reports). |
| `Use_Case_Diagram.drawio` | Use Case Diagram (draw.io file) — shows all actors (Admin, Doctor, Receptionist, Patient) and their interactions with the system. Open it at [draw.io](https://app.diagrams.net) to view/edit. |
| `Use_Case_Flow_Document.docx` | Use Case Flow — describes the step-by-step main flow, alternative flows, and exception flows for each use case shown in the diagram. |

## 👥 User Roles
- **Admin** – manages doctors, departments, and reports
- **Doctor** – manages medical records, prescriptions, and treatments
- **Receptionist** – manages patient registration, appointments, admissions, and billing
- **Patient** – books/views appointments and own records

## 🛠️ How to Use These Docs
1. Open the `Documents` folder in this repository.
2. Read `SRS_Document.docx` first to understand what the system does.
3. Refer to `Use_Case_Diagram.drawio` and `Use_Case_Flow_Document.docx` together to see how each user interacts with the system.
4. Use `Test_Plan_Document.docx` to test the system module by module.
